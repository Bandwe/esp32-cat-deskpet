# 小猫桌宠外壳 V01

适配对象：微雪 Waveshare **ESP32-S3-Touch-LCD-1.69**，依据官方 2024-06-06 STEP 模型建模。不是所有 1.69 英寸开发板的通用壳。

这是完整的第一版试装模型；已导出可打印 STL、可编辑 STEP、建模源代码和实际模型预览。**尚未进行实物打印、装配和使用验证。** 外观是否采用由你决定。

## 文件怎么用

| 文件 | 内容 | 数量 |
| --- | --- | --- |
| `print/body.stl` | 带短猫耳的前壳 | 1 |
| `print/lid.stl` | 可拆后盖，带定位边和内部支撑柱 | 1 |
| `print/stand.stl` | 可选直立底座，可直接拿起桌宠 | 1，可不打印 |
| `step/cat_case_assembly.step` | 三件外壳的装配模型，不含电子板 | 用于编辑 |
| `step/body.step`、`lid.step`、`stand.step` | 各零件实体模型 | 用于编辑 |
| `preview/cat_case_v01_preview.png` | 正面装配和后盖分离效果 | 用于查看 |
| `preview/03_print_parts.png` | 三件打印零件 | 用于查看 |

打印请使用 **`print/` 文件夹**，已经摆好打印方向并放在 Z=0 平面。`assembly/` 中的 STL 是装配坐标，不是打印摆放坐标。

预览来自实际 STL。图中的黑色屏幕和黄色猫眼是效果示意，**不属于打印零件，也没有更改板上程序**。

## 外形与结构

- 外壳含猫耳约 **宽 42.4 × 高 56.9 × 厚 14.8 mm**，不计螺丝头的突出量。
- 底座约宽 36 × 深 28 × 高 8 mm；装到底座后整体约高 59.9 mm。
- 屏幕玻璃采用官方模型尺寸，竖屏方向约宽 33.13 × 高 41.13 mm。
- 开窗约宽 31.73 × 高 39.73 mm；边框搭在玻璃周边，不另加透明面板，保留直接触摸玻璃的方式。
- 玻璃前表面相对壳体前缘内凹 0.8 mm；玻璃安装腔每边预留 0.35 mm。
- 正面看 USB 在左边，三个侧键在右边。USB 开口约 13 × 7 mm，仍需检查你所用数据线插头外壳是否能通过。
- 侧键留独立开孔，**本版没有外壳延长按钮**；是否便于用指尖或指甲操作需要试装确认。
- 四颗螺丝连接前壳和后盖，不穿过 PCB，不把板角金属区域当作螺丝通孔。
- 后盖内部支撑柱按官方模型避开元件，柱顶与 PCB 背面约留 0.45 mm，供薄软垫限位；不能靠强行拧紧后盖夹住电路板。
- 后盖有三个通气槽。没有为外加电池、扬声器等硬件预留经过验证的安装仓。
- 使用非金属材料；不要用金属片或金属漆包裹天线区域。装壳后仍需确认 Wi-Fi 表现。

## 还需要准备

1. 三个打印件，底座可选。
2. **直径约 2 mm、长度约 6 mm 的塑料用自攻螺丝 4 颗**。头径不超过 4.5 mm，建议小圆头；孔位为 1.7 mm 导孔、2.3 mm 过孔、4.5 mm 头部凹槽。具体咬合受耗材、螺纹形状和打印误差影响，先试一颗，不要强拧。
3. 约 0.5 mm 厚的非导电软垫少量，例如薄 EVA 或硅胶垫，剪成与支撑柱顶面匹配的小块。按实际间隙调整，贴在壳体支撑柱上，不贴在芯片、排线或按键上。
4. 小螺丝刀。底座脚垫可自行添加，但不是必需件。

不需要焊接，也不需要增加新的电子硬件。

## 建议打印设置

以下是起始建议，不是所有打印机都已验证的工艺参数：

- 第一轮可用 PLA 试装；准备长期使用时可考虑 PETG。避免放在阳光直晒、高温环境中。
- 0.4 mm 喷嘴，0.16–0.20 mm 层高，3–4 道墙，15–25% 填充。
- 单位选 **毫米**，比例 **100%**。不要整体缩放来修正局部装配问题，否则接口和螺丝位置也会改变。
- 前壳前脸朝打印平台，空腔朝上；后盖外表面朝平台、支撑柱朝上；底座底面朝平台。提供的 STL 已采用这些方向。
- 侧面接口有桥接区域，USB 开口跨度约 13 mm。根据打印机桥接能力，在切片中决定是否增加局部支撑，不能保证完全免支撑。
- 后盖有较细的支撑柱，去支撑和装配时轻拿轻放。
- 清理开窗、定位边和底部象脚，不要让硬毛刺接触玻璃；首件先不喷漆、不粘死。
- 想要预览的黑猫效果，可使用黑色耗材。先确认试装合适，再决定表面处理。

## 装配顺序

1. 断开 USB 和任何电池电源，在干燥、非导电的工作台上操作。
2. 前壳正面朝下放在软布上，从后方将板子玻璃朝前放入。确认 USB 朝左、侧键朝右，不压排线、接口或屏幕。
3. 先不装螺丝，检查玻璃能自然坐入、USB 和侧键对孔、后盖能合拢。如果需要明显用力，停止并找出干涉处，不能靠螺丝硬拉。
4. 在需要的内部支撑柱顶端放置薄软垫，确保只轻触无元件的 PCB 区域。若你的板卡版本或元件位置与官方模型不同，先不要安装。
5. 装后盖，四角交替缓慢拧紧。以不松动为止，不用电动工具大力锁紧。若后盖翘起、玻璃受压或侧键被持续按住，应立即松开检查。
6. 插入 USB，确认屏幕和触摸正常、侧键能释放、数据线插头到位，并检查联网情况。
7. 放入可选底座。底座为直立式、非卡死式，拿起桌宠后仍可使用原来的摇晃交互。

如果试装后有孔位偏差、按键难按或明显松动，记录位置并拍正反面照片；局部修改模型比整体缩放更合适。

## 可编辑源代码与重新生成

主要参数位于 `build_case.py` 顶部的 `P` 字典；`parameters.json` 只是生成时的参数记录，单独修改它不会改变模型。部分局部结构尺寸仍写在各建模函数中，修改后应重新核对配合关系。建议把后续修改另存为 V02，保留这版。

依赖版本见 `requirements.txt`。建议在本目录创建独立 Python 虚拟环境：

```powershell
python -m venv .venv-cad
.\.venv-cad\Scripts\python.exe -m pip install -r requirements.txt
```

重新生成需要官方 STEP，本仓库不包含该第三方源文件。请从下方官方链接下载 ZIP，将其中模型解压到：

`reference/board-3d/ESP32-S3-Touch-LCD-1_69.stp`

在本文件所在文件夹运行（已安装依赖的 Python）：

```powershell
python build_case.py
python render_preview.py --model-dir assembly --output-dir preview --print-dir print --screen 0 0 -0.8 33.13 41.13
```

运行会重新生成当前目录下的 STL、STEP、参数、检查报告和预览；修改前请先复制版本。
